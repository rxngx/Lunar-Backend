## Features:


- Lobby Support
- Locker Support
- Item Shop
- Refunding
- Discord Bot
- Discovery Tab
- Challenges
- Locations & Landmarks
- Challenges / Quests
- ClientSettings
- WinterFeast
- Season lightswitch
- Friends
- Gifting
- Battle Pass
- Automatic Item Shops
- Vbucks on kill/win
